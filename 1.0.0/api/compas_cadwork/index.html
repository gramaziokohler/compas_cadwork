    Transaction ¤

    Transaction()

    Helper for grouping several Cadwork operations in the same batch.

    This context manager is intended to be used when working with hundreds or thousands of elements, improving performance by deferring rendering until the end of the batch.

    It will also try to undo changes (rollback) in case of an error.

    Note

    Cadwork regenerates the ElementId of elements on undo/redo. Therefore, some element instances may become unusable on rollback.
